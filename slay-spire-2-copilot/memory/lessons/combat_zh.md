# HP 经济

- (2026-09-19) HP 兑换率随回合变化：前期/低威胁回合廉价，刀尖回合与 Boss 税窗口无价——每笔支出对照该回合换来什么（建议性）
- (2026-09-18) HP 经济墙是历史头号死因：Act 内多战消耗税 + 章切换满血假设 + 精英前无休息几何三者叠加

# 引擎上线

- (2026-09-19) 战斗开局：power/引擎件上线优先于边际伤害与小幅度省血；花早期 HP 换引擎件落地常是正确交易
- (2026-09-19) 自伤引擎按「每回合 −N HP」计入 Boss/精英生存预算

# 挡密度与致命回合

- (2026-09-18) Boss 战挡密度缺口是高频死因：进 Boss 前点名挡源数量 vs Boss 意图轮廓
- (2026-09-19) play 后落地验证：致命回合关键挡牌打出后重读 state 确认 block 数字再 end_turn（防「合法但缺失」）

# 竞速窗与税管理

- 术语：税 = 战斗中按回合/按张/按牌类强制征收的持续成本（区别于一次性伤害）——含 Power 税（敌人 power 每回合扣血/限牌，如 RINGING/解体/锁链）、状态牌税（塞状态牌稀释手牌，如 Beckon/Dazed）、技能税（按牌类收费，如 Vital Spark）、引擎自伤税（自家引擎每回合 HP 支出，如 Inferno tick/自伤燃料）；竞速窗 = 在税压垮你之前打完的时限
- (2026-09-18) 属性吸取类 Boss：免费窗是计时器，爆发资源必须在窗内砸完
- (2026-09-19) 弱化免疫伤害包（Power tick/遗物 tick/毒，至少两类）进 Boss 参考线
- (2026-09-19) Power 类税（RINGING/解体类）Cure All 无效——不为其留药位

# 机制查阅与 live 优先
