# 角色核心玩法（lessons）

跨局沉淀的角色玩法经验——建议性措辞，按 live 情况适配；机制/数值细节用 `spirectl lookup <id>` 查 data。

# IRONCLAD

- 建议性核心脊线：自伤燃料（放血/血墙/Brand/突破类 0 费自伤）→ Rupture 类力量泵 → 易伤窗爆发（重锤/Bludgeon 类大伤结算）
- 挡的来源建议以**消耗包**为主（无痛/重振精神/坚毅类），而非单卡堆叠；Boss 门前点数挡源数量 vs Boss 意图轮廓
- Boss 级答案参考：**弱化免疫引擎**（Power tick + 遗物 tick + 毒）——99 弱化类 Boss 面前传统力量脊线失效，攻击牌只是引擎窗口期的加速器
- 引擎自伤税（Inferno/深红斗篷类 tick）按「每回合 −N HP」计入 Boss/精英生存预算
- MaxHP 叠层是经济：狂宴/芝士/布质果实类喂牌滚 MaxHP，休息几何随之增值
- 0 费挡引擎（Rage 类）+ 空挡兜底遗物（Orihalcum 类）是「攻击密集回合无挡」死因类的结构性解

# SILENT

- 建议性脊线：附魔格挡引擎（漩涡附魔防御 × 脚下功夫 × 残影类单卡双结算格挡）+ 敏捷
- 毒与延迟伤害组件是 Boss 税战的弱化免疫伤害源之一

# REGENT

- 建议性脊线：星费回合 1 引擎（锻造 × 君主之刃 × 招架 × 征服者类组合，T1 直接成型）

# NECROBINDER

- 建议性脊线：Doom + 复生吸伤循环（链骨 × Doom × 吸伤）——成型后 Boss 战可零掉血
