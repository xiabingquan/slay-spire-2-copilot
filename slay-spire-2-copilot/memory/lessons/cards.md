# 卡牌经验（lessons）

跨局沉淀的卡牌用法——按角色卡池分节；建议性措辞，卡牌数据 lookup `spirectl_lib/data/cards.json`。

# IRONCLAD

- 重锤/Bludgeon 类：易伤窗主伤件——配合纸蛙/弹珠袋类易伤源，单回合爆发按易伤倍率算
- Whirlwind 类 X 费多段 AoE：多体同窗战（千足虫段组、波次敌）的结构性答案；按当前全部能量结算
- Burning Pact/True Grit/Second Wind 类消耗牌：状态稀释战（Infection/诅咒环境）价值高于边际攻击牌——消耗密度即解
- Fiend Fire 类手牌缩放爆发：多敌窗收段利器，费用按手牌数评估
- Rage 类 0 费挡引擎：攻击密集回合的挡密度答案；注意技能税局（如 Vital Spark 环境）对 power 标签牌的计税，以 live 意图为准
- Headbutt 类回收：把关键爆发件（PS/Bludgeon）回收进下一回合击杀窗
- Impervious 类大挡：Boss 致命回合的挡值银行——门前点数「大挡张数 vs Boss 峰值意图」
- Glam 附魔牌：每战首打双结算（如 Glam 耸肩 16 挡+抽2），后续单结算——首打时机规划有价值

# SILENT

- 刀刃之舞/偏折类 0 费技能链：链税环境下价值高于 2 费攻击
- 毒组件：弱化免疫伤害源，Boss 税战参考

# REGENT

- 君主之刃/招架类：回合 1 星费引擎组件，见 characters.md REGENT 节

# NECROBINDER

- 链骨/Doom 类：吸伤循环组件，见 characters.md NECROBINDER 节

# 通用/无色

- 打击/防御基础件在无升级经济时是稀释源；删牌位优先删打击
- Strike-tagged 卡受打击标签协同加成（如某些遗物/事件附魔），牌组标签意识有价值
