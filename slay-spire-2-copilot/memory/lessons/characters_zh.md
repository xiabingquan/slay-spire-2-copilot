# IRONCLAD（铁甲战士）

- (2026-09-18) 胜法脊线：自伤燃料（放血/血墙/Brand/突破类）→ 力量泵 → 易伤窗爆发；挡靠消耗包（无痛/重振精神/坚毅类），不靠单卡堆叠
- (2026-09-18) 0 费能量牌是爆发回合的支付层；消耗类挡牌比基础防御更可靠
- (2026-09-19) Boss 级胜线 = 弱化免疫引擎为脊（Power tick + 遗物 tick + 毒），攻击牌只是引擎窗口期的加速器；99 弱化 Boss 面前传统力量脊线失效
- (2026-09-19) A1 稳定双脊 = 弱化免疫引擎 + 挡引擎（Glam 首打双结算 / Rage×Orihalcum 空挡兜底），两条脊尚未在同局会师
