# User guide（用户指南）

记忆写作指南：格式在哪、记什么，以及反思时机 / 建议性口吻 / 何时查阅
记忆这几条常备指示。

## 格式

格式不在本文件复述——直接遵循指定文档：

- 每局笔记（`memory/runs/` 下的英文 + `_zh` 中文对）：格式遵循
  `memory/template.md`——Summary 事实表、Run overview 逐 Act 表，以及
  What went well / What went poorly / Key moments 三张表
- 跨局总览表、阶段性反思、SL 列：规则遵循 `memory/overview.md` 自身
  （其表格规则块与 `# 阶段性反思` 节）

## 记什么

- 只记前向价值：对后续对局决策有帮助的内容——复仇叙事、过程/修复日志
  绝不进记忆
- run 笔记表格里：值得复用的发挥、决策级损失、本局转折点——决策与客观
  因素都记
- `memory/lessons/` 里：跨局常备经验——角色脊线、敌人教条、协同、
  事件/经济/战斗笔记（每类一个文件；经验格以建议性条目填写）
- 机制事实哪里都不记：用 `spirectl lookup <id>` 解析——数据存储是程序化
  的（codex 为权威源）。系统侧缺陷在所属系统当场修复，绝不作为 run
  factor

## 阶段性反思触发时机

- **第一次**反思覆盖当时为止已记录的**全部**对局
- **此后每次**覆盖自上次以来的 20 局（第二次覆盖 36–55，第三次 56–75，
  ……）——累计对局数到达该边界时触发

## 经验是建议性的，不是硬性模式

- 措辞：优先「建议… / 参考… / run-X observed…」，避免「强烈建议 /
  强烈建议不要」
- **所有过去对局仅供参考。**局内具体措施必须依据当前局的 live 状态
  （HP、牌组、手牌、敌人、地图几何）来定，绝不从旧笔记或 lessons 整体
  照搬
- 过去经验只是输入之一，live 情况永远优先——局中查阅记忆时把旧笔记当
  数据读、再适配，不要照搬另一局的剧本

## 何时查阅记忆

- **会话/开局强制项：只读 `overview.md`**——表格、统计与阶段性反思构成
  跨局全景；单局笔记开局时一般不需要
- **`lessons/` 局中随时查**——决策受益时：敌人教条、协同、角色脊线；
  机制数值先用 `spirectl lookup <id>` 解析
- **按需读单局**：文件名带对局序号前缀（`0051_IRONCLAD_...`），与
  overview.md 的对局序号列对应——查号后开文件
- 游玩过程中任何时候，只要决策会受益于历史记录
