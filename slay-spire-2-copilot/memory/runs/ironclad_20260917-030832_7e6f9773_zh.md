## What went poorly

- **起始远古赐福房被跳过**：本局最重的流程失误。
  `run.map.rows[]` 明明暴露了 (0,3)=Ancient；章节切换那回合 agent 根本没查
  它。规则现已写死进 SKILL：必须最先处理 `run.act_start_room`
  （visited=false 且 is_boon_room=true）——state 会把该点重新注入
  available_map_points，紧凑视图会打印 ACT-START BOON ROOM UNVISITED 警告。
- **重启过多**：本局 5+ 次游戏重启（死锁逃生 ×3 + mod 修复加载 ×2，
  其中一次 install-mod.sh 在错误目录执行）。新节奏：代码改动
  合批、每批只重建+重启一次；死锁逃生（relaunch+continue_run）仅作最后手段。
- **phase=End 卡死**：空手 PlayerCmd 路径已触发（第 2 局的修复生效）但战斗
  仍冻结在 PlayerTurnPhase.End——敌方回合不结算；force_advance 重排队到
  同一道闸。Proposal 待办：phase=End + fingerprint 冻结时绕过 Play 阶段
  守卫 / 直接解挂动作队列。
- **药水选牌界面仍不可见**：COLORLESS_POTION 已消耗但 state 无 card_choice
  （第二次确认；SKILL_POTION 同样）。StateBuilder 需覆盖战斗中打开的
  NChooseACardSelectionScreen。
- **章节切换时 bridge state 滞后**：proceed 后 state 只列第 1 排点；
  map.rows 才是真相。教训：任何章节切换后，动手前先 dump `run.map`——
  紧凑视图不够用。

## 机制补录（确定性来源：sts2.dll v0.107.1 反编译——2026-09-17）

本局接触过但上文未写清机制的元素，精确效果如下（来源为游戏程序集
反编译，非对局记录推测）：

- OROBIC_ACID（药水，稀有，仅战斗中，指定自己）：从本角色卡池随机
  各生成 1 张攻击牌 + 1 张技能牌 + 1 张能力牌置入手牌，本回合内三张
  全部 0 费。（本局：攻击位开出 BREAKTHROUGH，AoE 清掉史莱姆波——即
  上文"免费卡回合"。）
- BULLY（卡牌，0 费攻击，罕见）：伤害 = 2 × 目标当前易伤层数
  （升级后：3 × 层数）。易伤目标的真终结技——上文 boss 收尾的
  "0 费终结"。
- CRIMSON_MANTLE（卡牌，1 费能力，稀有）：打出时获得
  CrimsonMantlePower 8——每个己方回合开始失去 1 HP（不可格挡）并
  获得 8 点格挡。升级：格挡 8→10。
- SETUP_STRIKE（卡牌，1 费攻击，普通）：造成 7 点伤害并获得 2 点
  临时力量（SetupStrikePower 继承 TemporaryStrengthPower）。
  升级：伤害 +2、力量 +1。
- TREMBLE（卡牌，1 费技能，普通）：对一名敌人施加 3 层易伤，消耗。
  升级：易伤 3→4。
- BLUDGEON（卡牌，3 费攻击，罕见）：单体 32 点伤害。升级：32→42。
- MEAL_TICKET（遗物，普通）：进入商店房（MerchantRoom）时回复 15 HP。
  仅在第三章宝箱前可能出现。
- BELLOWS（遗物，稀有）：每场战斗第 1 回合开始时，将手牌中所有卡牌
  本场战斗内升级。
- HAPPY_FLOWER（遗物，罕见）：每 3 回合 +1 能量（本 session 早期
  perplexity 调研结论；与第 3/6 回合观察一致）。
- HARD_TO_KILL（能力，外骨骼虫系）：每回合 HP 损失上限 9（本 session
  早期调研结论；按 ~9/回合 节奏输出）。
