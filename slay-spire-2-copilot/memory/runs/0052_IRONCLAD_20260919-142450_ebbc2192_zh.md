## Run review

进阶 1 以 live 校验（state `asc=1`；overview 统计 A1 = 2/3 通过 → 按策略维持 A1）。路线草稿开局东线；(5,6)/(6,5) 分岔触发中局修订——以 3/3 药水带为储备立即打精英 (6,5)，随后休息 (7,5) → 商店 (8,6) → 宝箱 (9,6) → 精英 (10,6)。双精英均 T4 击杀（旧日雕像、多尼斯异鸟）；商店沉淀 214/218 = 98.2%。通往 Boss 的怪物走廊另有三战（蛮兽、缩小甲虫+毛绒伏地虫、双小啃兽）+ (15,6) 休息把 26→50 后进 Boss 门。

Boss 战是近期 A1 有记录以来最强的 Act1 Boss 伤害表现：252 → 77，眩晕窗剧本精确执行，但血量经济在回合消耗战中落败。本局全部陌生 id 均在出牌前 lookup 解析（蛮兽、飞蝇菌子、缩小甲虫、蛇行扼杀者、闪光贾克斯果、旧日雕像、多尼斯异鸟、仪式兽全循环）——零盲打。

## What went well

- **眩晕窗剧本 live 兑现**：T6 跨界一击 21 伤 → Boss 141/252 → move=STUNNED，PLOW_POWER 被剥离、Boss 力量被吞噬、Plow 26 取消——run-23 的 150 阈值订正在桥上再次确认。
- **Rupture×2 跨副本叠层 live**（run-27–35 脊线模式）：Boss 战第二张 Rupture 把 RUPTURE_POWER 从 1 抬到 2；深红斗篷回合开始税随后每回合 +2 力——Boss 战力量从 4 爬到 14；放血/血墙/突破每次自伤各付 +2。
- **商店红骷髅（178g）兑现**：≤40HP 的 +3 力量窗在多尼斯异鸟战（str 5 Setup 链）、缩小甲虫战、双小啃兽战、Boss 战均触发——把危险血线变成竞速窗，与遗物文本一致。
- **路线中局修订值回票价**：双精英之间夹休息+商店+宝箱，优于保守单精英脊线；精英奖励为 JOSS_PAPER + 仙灵药 + 火焰屏障 + 药水带。
- **药水储备策略**：易伤药花在旧日雕像睡眠自由窗（run-48 级竞速）；屈伸药水压到 Boss 兽吼自由窗——单回合 64 伤。
- **仙灵药 live 触发**：双小啃兽战中被深红斗篷税致死时以 30% Max（24/80）复活——复活价值确认，消耗记为终局储备成本。
- **Joss Paper × 第二阵风组合 live**：SW 消耗推进计数（:0→:1）；遗物×消耗挡包组合成立。
- Setup Strike live 复确认：其自身一击不吃临时力量，价值落在后续攻击上——爆发链须以它起手。

## What went poorly

- **Cure All vs RINGING——过程债**：run-51 的 live 订正（Cure All 不解 Power 类税）就在 overview 统计行里，T8 仍对 RINGING_POWER 打出，药水零效果消耗；T8 在桥的 `no(None)` 闸门下被迫收缩为单卡 Defend 线。参考性建议：打出净化类药水前检查目标税 id 是否带 `_POWER`——带则预期无效。
- **Boss 血线核算**：以 50/80 进门（放弃骷髅换缓冲——相对 26 是正确取舍）仍挡不住 Plow 升到 24–26/回合后的消耗；引擎铺垫回合（T3 Rupture+Mantle、T4 Rupture#2+FB）以 15+2 HP 为代价买到竞速包，而当回合手牌挡量单薄。参考性建议：竞速 ≤150 级眩晕阈值时，把每个铺垫回合定价为（敌方意图 − 可用挡）+（引擎自伤），再决定铺引擎还是打伤害。
- **引擎税成为击杀工具**：深红斗篷 −1/回合在长战前段是优质挡经济，在 1HP 处是致命负债——本局加入 run-41/42/45 的自伤 tick 死亡类。参考性建议：把 Mantle+BL+BT 的每回合 HP 成本与敌方意图一起计入 Boss 生存预算，「HP ≤ 预计引擎税」视为自伤牌硬停线。
- **仙灵药花在 Boss 前**：双小啃兽战消耗了复活储备，Boss 走廊零容错。参考性建议：仙灵药类读作 Boss 走廊储备——走廊战 1HP 致死线或许值得换更重的挡线。
- **弱化药差 9g 未入手**：(8,6) 商店红骷髅 178 + 岩石铠甲 36 = 214/218，弱化药 49 不可及——Boss 门储备类别缺口在门上显形。
- **164 金死时未花**：(9,6) 之后的脊线无商店；结构性记录——路线草稿层面：过宝箱后的金币在此图几何上无沉淀口。
- **Whetstone 混合打击池**：仅部分打击被升级（live 6 与 9 伤并存）——静态 PS/击杀数学需要 live 伤害读数校准；本局伤害公式以 state 打印为准。
