# 卡牌

确定性卡牌机制，提取自反编译卡牌类
（`/tmp/sts2-decomp/MegaCrit.Sts2.Core.Models.Cards/*.cs`）与角色卡池
（`MegaCrit.Sts2.Core.Models.CardPools`）。数据来源：构造函数
base(cost, CardType, CardRarity, TargetType)、CanonicalVars DynamicVar 数值、
OnPlay 指令逻辑、OnUpgrade 增量、CanonicalKeywords。能力牌效果对照
`MegaCrit.Sts2.Core.Models.Powers/*.cs` 验证。无实战叙事、无猜测区间。
每张卡一行；与 cards.md 顺序一致。

费用说明：X 费卡在构造函数中记为 0 或 -1，打出时经
ResolveEnergyXValue() / ResolveStarXValue() 结算 X；下文统一记作 X。
