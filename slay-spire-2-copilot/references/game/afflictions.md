# Afflictions and statuses

Static reference for card-bound debuffs and status cards.

- BYRDONIS_EGG (nest/Sapphire Seed events): unplayable (-1 cost) dead draw;
  remove via shop. HATCH rest option appears while in deck.
- SLIMED-type status cards: enemy-inflicted; some playable for minor effect.
- DECAY / WOUND: enemy/event statuses; chip damage or SECOND_WIND fuel;
  shop-removal targets.
- RINGING: on player, hand cards flip can_play=false (RINGING_POWER).
- Card-bound afflictions (Bound, Entangled, ...) are pointers to their Power
  logic — see powers.md for the actual effects.
