# Cards

Deterministic card mechanics extracted from decompiled card classes
(`/tmp/sts2-decomp/MegaCrit.Sts2.Core.Models.Cards/*.cs`) and character pools
(`MegaCrit.Sts2.Core.Models.CardPools`). Per card: base constructor
(cost, CardType, CardRarity, TargetType), CanonicalVars DynamicVar values,
OnPlay command logic, OnUpgrade deltas, CanonicalKeywords. Power-card effects
verified against `MegaCrit.Sts2.Core.Models.Powers/*.cs`. No run narratives,
no observed ranges. One line per card; same order as cards_zh.md.

Cost note: X-cost cards are encoded as cost 0 or -1 in the constructor and
resolve X via ResolveEnergyXValue() / ResolveStarXValue() on play; they are
listed below as X.
